하루 설명서

하루에 들어 있는 기능을 한곳에 모았어요. 처음 쓴다면 시작하기부터 읽고, 나머지는 필요할 때 위 목차에서 골라 보면 돼요.

버튼 위에 마우스를 올리면 이름이 나오니까, 설명서에 나온 이름으로 찾으면 돼요.

시작하기화면 둘러보기일정 적기캘린더·할 일우클릭·잠금여러 개 고르기옮기기·복사루틴주차위치·숨기기·단축키디자인 설정설정동기화·업데이트문제 해결

시작하기

설치하고 구글에 로그인하면 바로 쓸 수 있어요.

  1. 내려받기 페이지에서 HaruSetup-버전.exe를 받아 실행해요.
  2. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 눌러요. 개인이 만든 프로그램이라 처음 한 번 떠요.
  3. 설치 화면에서 설치 위치, 바탕화면 바로가기, 윈도우 시작 시 자동 실행을 고르고 설치해요.
  4. 하루 오른쪽 위 계정 아이콘 → 구글 계정으로 로그인. "확인되지 않은 앱" 화면이 나오면 고급 → 하루(으)로 이동을 눌러요.
  5. 처음 연결할 때 이 PC에만 적어 둔 일정이 있으면 구글로 옮길지 물어봐요.

하루는 따로 서버가 없어요. 일정은 내 PC와 구글 사이에서만 오가요. 자세한 내용은 개인정보처리방침에 있어요.

일정 적기 (날짜 팝업)

날짜 칸을 더블클릭하면 그 칸 위에 팝업이 떠요. 메모장처럼 한 줄에 일정 하나씩 적으면 돼요.

키 조작

  • Enter 다음 줄 · 시간 칸에서 Enter는 메모 칸으로
  • 빈 줄에서 Backspace 줄 지우기
  • Ctrl+Enter, ✓, 팝업 바깥 클릭 = 저장
  • Esc, ✕ = 취소
  • 여러 줄을 붙여 넣으면 줄마다 나뉘어요. 13:30 회의처럼 앞에 시간이 있으면 시간 칸으로 들어가요.
  • 여러 날 일정은 첫날 팝업에서 고쳐요. 다른 날 팝업에서는 위쪽에 따로 보이고 지울 수 있어요.
  • 생일·구독 캘린더처럼 보기만 되는 캘린더의 일정도 팝업 위쪽에 따로 보여요.
  • 새 일정이 들어갈 캘린더는 설정 → 저장할 캘린더에서 정해요.
  • 칸에 일정이 넘치면 칸 위에서 마우스 휠로 스크롤해요. 아래에 작은 화살표가 보여요.

캘린더 · 색 · 할 일 · 공휴일

  • 캘린더 목록에서 켜고 끈 체크는 구글 캘린더 웹과 같이 바뀌어요.
  • 일정 색은 구글에서 그 일정에 정한 색, 없으면 캘린더 색이에요. 배경색으로 칠할지 글자색으로 칠할지는 디자인 설정에서 골라요.
  • 마감일이 있는 구글 할 일(Tasks)은 체크박스와 함께 칸에 보여요. 체크박스를 누르면 완료 / 완료 취소.
  • 할 일 색은 캘린더 목록의 "할 일" 색 네모를 눌러 골라요. 이 PC에만
  • 여러 날 일정은 칸을 넘어가는 막대로 보여요.
  • 대한민국 공휴일·기념일이 날짜 옆에 보이고, 공휴일 숫자는 일요일 색이에요. 둘 다 디자인 설정에서 끌 수 있어요.

우클릭 메뉴 · 잠금

일정·여러 날 막대·할 일을 우클릭하면

  • 캘린더 변경 · 할 일로 바꾸기 / 일정으로 바꾸기 · 완료 · 잠그기 · 삭제
  • 루틴으로 지정… (루틴이면 루틴 수정… · 이 날만 삭제 · 루틴 일괄 삭제)

잠금 이 PC에만

실수로 지우거나 고치지 않게 막는 기능이에요.

  • 날짜 잠금: 날짜 칸 우클릭 → ○월 ○일 잠그기. 그날 팝업이 보기 전용이 돼요.
  • 일정 잠금: 일정 우클릭 → 잠그기. 팝업에서 지우거나 고칠 수 없어요.
  • 잠금 편집 모드: 제목줄 자물쇠 → 날짜 빈 곳이나 일정을 누를 때마다 잠김/풀림. 끝내려면 위쪽 ✓.

날짜 칸 빈 곳을 누르고 끌면 평소처럼 바탕화면 선택 네모가 그려져요. 하루 아래에 있는 바탕화면 아이콘도 같이 선택돼요.

여러 개 고르기

일정과 할 일을 섞어서 여러 개 골라 한 번에 처리할 수 있어요.

조작결과
Ctrl+클릭하나씩 더하기 / 빼기
Shift+클릭처음 Shift+클릭한 것부터 이번 것까지 날짜순으로 전부
Shift+드래그네모 안의 것. 네모 안이 이미 전부 골라져 있으면 해제, 하나라도 아니면 전부 선택
Delete골라 둔 것 한꺼번에 삭제 (확인 창이 떠요)
우클릭한꺼번에 삭제 · 색 · 캘린더 · 완료 · 잠금
Esc / 빈 곳 클릭선택 해제
  • 지금 보는 달 안에서만 고를 수 있고, 달을 넘기면 선택이 풀려요.
  • 잠긴 것과 보기 전용 캘린더의 일정은 고를 수 없어요.
  • 골라 둔 일정이 어떻게 보일지는 디자인 설정 → 선택 표시에서 바꿔요.

끌어서 옮기기 · 복사

  • Ctrl·Shift로 골라 둔 일정만 끌 수 있어요. 안 고른 일정은 실수로 옮겨지지 않게 안 끌려요.
  • 다른 날짜에 놓으면 골라 둔 것 전체가 날짜 간격·시간·기간 길이를 그대로 지킨 채 옮겨져요.
  • 놓을 때 Ctrl을 누르고 있으면 복사, 떼면 이동이에요. 탐색기와 같아요.
  • Esc로 취소. 잠긴 일정·잠긴 날짜·보기 전용 캘린더는 안 되고, 루틴은 그날 것만 옮겨져요.

루틴 (반복 일정 · 할 일)

제목줄 루틴 아이콘을 누르면 루틴 창이 열려요. + 새 루틴으로 만들고, 목록에서 고르면 고칠 수 있어요.

정할 수 있는 것

  • 종류: 일정 / 할 일
  • 제목, 시간 (비우면 하루 종일), 캘린더, 색
  • 반복: N주마다 고른 요일 (격주 화요일 등) / N일마다
  • 시작일, 끝: 계속 · 종료일 · 횟수

일정 루틴과 할 일 루틴

  • 일정 루틴은 구글 캘린더 반복 일정으로 저장돼서 폰·웹에서도 똑같이 반복돼요.
  • 할 일 루틴은 구글 할 일이 반복을 지원하지 않아서, 하루가 2달 앞까지 날짜마다 할 일을 만들어 둬요. 그 뒤 날짜는 흐린 '예정'으로 보여요.
  • 있던 일정·할 일도 우클릭 → 루틴으로 지정…으로 루틴이 돼요. 반복은 그 날짜부터 시작해요.
  • 날짜 팝업에서 루틴 일정 하나를 고치면 그날 것만 바뀌어요. 전체를 바꾸려면 루틴 창에서 고쳐요.
  • 우클릭 → 이 날만 삭제 또는 루틴 일괄 삭제.
  • 루틴 창 → 달력에서 골라 지우기: 루틴 일정에 마우스를 올리면 같은 루틴이 빨간 테두리로 모두 보여요. 우클릭 → 삭제하면 통째로 지워져요. 끝내려면 Esc.
  • 할 일 루틴을 지우면 완료 안 한 것만 지워지고, 완료한 기록은 남아요.

주차 이 PC에만

학기처럼 기간을 정해 두면 달력에 "3주차"처럼 보여 줘요. 제목줄 주차 설정 아이콘에서 + 새 기간을 눌러 만들어요.

  • 정하는 것: 이름 (예: 2026-2학기), 시작일, 한 주기 일수 (기본 7일), 단위 이름 (주차·회차…), 끝 (주기 수 / 종료일 / 끝 없음), 기간 색
  • 시작하는 요일이 곧 주차가 바뀌는 요일이에요. 화요일에 시작하면 화요일~다음 주 월요일이 1주차예요.
  • 기간은 여러 개 만들 수 있어요. 메인 기간 하나만 날짜 숫자 뒤에 막대로 쭉 이어지고, 나머지는 주차 첫날에 ● 3주차로 보여요.
  • 주차 글씨를 누르면 그 기간이 메인이 되고, 끌어서 다른 글씨 앞·뒤에 놓으면 순서가 바뀌어요. 주차 설정 목록에서도 끌어서 바꿀 수 있어요.
  • 주차 막대·글씨 우클릭 → 간편 설정: 이 날부터 다시 세기, 이 날까지만, 한 주기 길이, 색, 삭제
  • 날짜 칸 우클릭 → ○월 ○일부터 주차 세기…로 바로 만들 수도 있어요.

위치 · 크기 · 숨기기 · 단축키

위치·크기 조절

  • 제목줄 위치·크기 조절 → 아무 곳이나 끌어서 옮기고, 가장자리·모서리를 끌어 크기를 바꿔요.
  • 화면 끝과 작업표시줄에 가까이 가면 자석처럼 붙어요.
  • 다 정했으면 완료를 눌러 고정해요. 처음 자리로 돌리려면 기본 위치로.

숨기기

  • 메뉴(…) → 하루 숨기기. 숨겨도 동기화와 업데이트 확인은 계속돼요.
  • 시계 옆 알림 영역 하루 아이콘: 클릭 = 보이기/숨기기, 우클릭 = 오늘 일정 적기, 잠깐 맨 앞에 보기, 설정, 종료
  • 숨긴 채로 끄면 다음에도 숨긴 채로 시작해요.

단축키 (윈도우 어디서든)

기본값기능
Ctrl+Alt+H하루 보이기 / 숨기기
Ctrl+Alt+N오늘 일정 바로 적기 — 다른 창 위로 떠서 오늘 팝업이 열려요
Ctrl+Alt+C잠깐 맨 앞에 보기 — 다른 곳을 누르면 다시 맨 뒤로 가요

바꾸려면 설정의 단축키 칸을 누르고 원하는 조합을 그대로 눌러요. Backspace는 그 단축키 끄기예요.

디자인 설정

바꾸는 즉시 달력에 미리 보여요. 이 탭 기본값으로를 누르면 지금 탭만 처음 상태로 돌아가요.

테마

이름느낌
하루 (기본)차분한 어두운 회색 + 햇살색 강조
라이트밝은 반투명 흰색
글래스거의 투명, 바탕화면이 잘 비쳐 보여요
밤하늘짙은 남색 + 하늘색 강조
모스짙은 초록
  • 전체 불투명도: 테마 색은 그대로 두고, 글자만 빼고 배경·테두리·일정 색·주차 막대를 한꺼번에 투명하게 해요.
  • 색상 · 불투명도: 색 네모를 눌러 고르거나 #RRGGBB로 직접 적어요. 하나라도 바꾸면 테마가 '사용자 지정'이 돼요. 일정 글자가 '자동'이면 일정 색에 맞춰 흰 글씨·검은 글씨를 알아서 골라요.
  • 글꼴 · 글자 크기
  • 표시: 주 시작 요일 (일요일 / 월요일), 일정 색을 글자 배경색 또는 글자색으로, 칸 테두리, 주말 칸 색, 일요일·토요일 숫자 색, 지난달·다음 달 날짜, 공휴일·기념일 이름, 공휴일 숫자 색
  • 선택 표시: 글로우 (기본) / 링 / 밝게 / 어둡게 / 나머지 흐리게, 강조 색, 세기
  • 주차: 표시 방식 (메인 막대 + 글씨 / 메인 막대만 / 막대 없이 시작일 글씨만 / 모든 날짜에 글씨), 주차마다 진하게·연하게 번갈아 칠하기, 기간 색 7가지, 제목줄 오늘 날짜 옆에 몇 주차인지 표시

설정

  • 자동 동기화 주기: 폰·웹에서 넣은 일정을 가져오는 간격. 1분~1시간 중에서 고르고, 기본은 5분이에요. '끄기'로 두면 동기화 버튼을 눌렀을 때만 가져와요. 하루에서 적은 일정은 주기와 상관없이 저장하는 즉시 올라가요.
  • 달력 위에서 마우스 휠로 달 넘기기: 위로 굴리면 이전 달, 아래로 굴리면 다음 달. 일정이 넘치는 칸 위에서는 그 칸 안이 스크롤돼요.

문제 해결

시계 옆에 하루 아이콘이 안 보여요
Windows 11에서는 새 아이콘이 처음에 숨겨져 있을 수 있어요. 시계 옆 ^를 눌러 하루 아이콘을 찾고, 작업표시줄로 끌어다 놓으면 항상 보여요.
숨긴 하루를 다시 꺼내고 싶어요
Ctrl+Alt+H를 누르거나 시계 옆 하루 아이콘을 클릭해요.
일정이 동기화가 안 되거나 로그인이 풀렸어요
오른쪽 위 지금 동기화를 누르면 다시 로그인 창이 떠요. 계정 아이콘에서 지금 로그인한 계정과 동기화 상태를 확인할 수 있어요.
단축키가 등록되지 않았다고 나와요
다른 프로그램이 이미 그 조합을 쓰고 있어서 그래요. 설정에서 다른 조합으로 바꿔 주세요.
일정을 고칠 수 없어요
그 날짜나 일정이 잠겨 있거나, 생일·구독 캘린더처럼 보기만 되는 캘린더의 일정일 수 있어요. 우클릭 메뉴나 잠금 편집 모드에서 잠금을 풀어요.
설치할 때 "Windows의 PC 보호" 창이 떠요
개인이 만든 프로그램이라 처음 한 번 떠요. 추가 정보 → 실행을 누르면 돼요.

하루는 바탕화면에 붙어 있어서 바탕화면 보기를 해도 그대로 보여요. 작업 중에 잠깐 보고 싶으면 Ctrl+Alt+C를 눌러요.
