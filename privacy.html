한눈에 보기
  • 하루(Haru)는 Windows PC에서만 동작하는 프로그램이며, 별도의 서버가 없습니다.
  • Google 계정 데이터는 사용자의 PC와 Google 사이에서만 오가며, 개발자를 포함한 제3자에게 전송되지 않습니다.
  • 광고, 분석 도구, 사용 기록 수집을 하지 않습니다.

1. 하루가 접근하는 Google 데이터

사용자가 하루에서 Google 계정으로 로그인하고 동의한 경우에만 아래 데이터에 접근합니다.

데이터 (권한)사용 목적
캘린더의 일정
calendar.events		사용자가 체크해 둔 캘린더의 일정을 바탕화면 달력에 표시하고, 사용자가 하루에서 직접 추가·수정·삭제하거나 다른 캘린더로 옮긴 일정을 Google 캘린더에 반영합니다. 일정의 표시 순서를 기억하기 위해 일정의 비공개 확장 속성(haruOrder)에 순번을 저장합니다.
캘린더 목록
calendar.calendarlist		캘린더 목록(이름, 색, 체크 상태)을 표시하고, 사용자가 하루에서 캘린더 체크를 바꾸면 Google 캘린더의 체크 상태도 같이 바꿉니다. 캘린더를 새로 만들거나 지우지 않습니다.
할 일
tasks		마감일이 있는 Google 할 일(Tasks)을 달력에 표시하고, 사용자가 하루에서 체크하면 완료 또는 완료 취소로 바꿉니다. 사용자가 우클릭 메뉴에서 일정을 할 일로 바꾸거나 할 일을 삭제할 때만 할 일을 만들거나 지웁니다.
공개 캘린더의 일정
calendar.events.public.readonly		Google이 공개한 대한민국 공휴일 캘린더를 읽어 공휴일과 기념일을 표시합니다.
이름, 이메일 주소, 프로필 사진
openid · email · profile		현재 로그인한 계정을 계정 메뉴에 표시합니다.

하루는 사용자가 직접 한 동작(일정 작성·수정·삭제·캘린더 변경, 할 일 완료·삭제, 캘린더 체크)과 화면 표시에 필요한 경우에만 데이터를 사용합니다. Gmail, Drive 등 그 밖의 Google 데이터에는 접근하지 않습니다.

2. 데이터가 저장되는 곳

하루가 저장하는 모든 데이터는 사용자 PC의 %LocalAppData%\Haru 폴더에만 저장됩니다.

  • 로그인 정보(토큰): 매번 다시 로그인하지 않도록 Google이 발급한 인증 토큰을 저장합니다.
  • 계정 정보: 계정 메뉴 표시를 위한 이름, 이메일, 프로필 사진 주소
  • 일정·할 일·캘린더 목록 사본: 인터넷이 끊겼을 때도 달력을 보여 주기 위한 사본과, 아직 Google에 올리지 못한 변경 내역
  • 공휴일 목록과 화면 설정(위치, 크기, 색, 글꼴, 단축키, 잠근 날짜·일정 목록 등)

이 파일들은 다른 곳으로 전송되지 않습니다.

3. 데이터 공유 및 제3자 제공

하루는 Google 사용자 데이터를 판매하거나, 개발자를 포함한 어떤 제3자에게도 전송·공유하지 않습니다. 광고 목적이나 사용자 분석 목적으로 사용하지 않으며, 사람이 데이터를 열람하지 않습니다.

하루가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Limited Use(제한적 사용) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

4. 그 밖의 통신

새 버전이 있는지 확인하기 위해 하루는 주기적으로 GitHub(api.github.com)에 최신 버전 정보를 요청하고, 사용자가 업데이트를 누르면 GitHub에서 설치 파일을 내려받습니다. 이때 Google 계정 정보나 일정은 전송되지 않습니다.

5. 데이터 삭제 및 연결 해제

  • 로그아웃: 하루의 계정 메뉴에서 로그아웃하면 Google에 토큰 폐기를 요청하고, PC에 저장된 로그인 정보를 삭제합니다.
  • Google에서 연결 해제: Google 계정 → 서드파티 앱 및 서비스에서 하루의 접근 권한을 언제든 삭제할 수 있습니다.
  • 모든 데이터 삭제: 하루를 제거한 뒤 %LocalAppData%\Haru 폴더를 지우면 PC에 남은 데이터가 모두 삭제됩니다. Google 캘린더에 있는 일정은 Google 캘린더에서 관리합니다.
